# Generic GST Cloud App (React)

Welcome to the Generic GST Cloud Application! This is an enterprise-grade React application built for managing multi-tenant GST compliance, returns filing, and reconciliation.

## Tech Stack
* **Framework:** React 18
* **Bundler:** Vite
* **State Management:** Redux Toolkit & React Context
* **Styling:** Bootstrap, SASS, Styled Components
* **Data Grids:** Handsontable, React Data Grid

## Quick Start
1. Run `npm install` (or `yarn install`) to install all dependencies.
2. Ensure you have copied `.env.example` to `.env` and configured your local environment variables.
3. Run `npm run dev` to start the local Vite development server.

## Scripts
* `npm run dev` - Starts the development server
* `npm run build` - Builds the application for production
* `npm run lint` - Runs ESLint to check for code issues
